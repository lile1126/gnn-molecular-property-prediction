
## 6. 已知问题与处理

1. **`git push` 失败**：本机访问 GitHub 时 `schannel: failed to receive handshake, SSL/TLS connection failed`。本地 commit 与 tag 已完整创建；推送需换网络/代理或改用 SSH，未在代码层做绕过。
2. **GNNExplainer 非确定性**：默认实现有随机掩码初始化。`explanation_consistency.py` 已按（分子, 配置）固定种子；单模型 Web 解释仍是近似结果，不应视为唯一真值。
3. **matplotlib 在无显示环境报 TkAgg 错误**：绘图脚本已显式 `matplotlib.use("Agg")`；新增脚本若绘图需同样处理。
4. **`FreeSolv` 的 MC-Dropout 区间覆盖率不足**：这是模型局限，不是代码 bug；报告已标注，不作为严格置信区间。
5. **BBBP 骨架划分正样本少**：未纳入多种子复验；Clintox 骨架 test 仅 5 个正样本，同样不纳入。
6. **模型体积**：`models/` 共 294 个 `.pt`，Git 仓库通过强制添加保存了冻结版本；后续新增实验请在新分支，避免与 `v1.0-freeze-144ckpt` 冲突。
