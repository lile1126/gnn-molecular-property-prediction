# 3–5 分钟现场演示脚本

**目标**：在不依赖 DeepSeek API 的情况下，稳定展示"单条预测 → 批量预测 → 导出 → 解释一致性/官能团/模型版本"，并预留断网与缺模型时的兜底话术。

**演示前 3 分钟准备**

```bash
cd D:\桌面\工程实践\GNN分子性质预测
.\.venv\Scripts\python.exe src\app.py
```

浏览器打开 `http://127.0.0.1:5000`，确认页面底部显示模型版本行（tag `v1.0-freeze-144ckpt`、checkpoint 总数），右上角无红色报错。若端口被占用，用 `python src/app.py --port 5001`（或结束占用进程后重启）。

## 0:40–1:40 单条预测（阿司匹林）

**动作 1**：在输入框粘贴：

```
CC(=O)Oc1ccccc1C(=O)O
```

**动作 2**：任务选 `ESOL 水溶解度`，特征档选 `FEAT_C`，架构选 `GCN`，分析方式选 `异质集成`，点击"预测"。

**预期结果**（与本机 smoke 测试一致，允许小幅浮动）：

- 预测值约 `0.386 logS`（异质集成）；若切回单模型 GCN_featc，约 `0.600 logS`；
- 结构图出现原子着色；
- 解释一致性 pill 显示 `高`（ESOL，Top-10 原子 Jaccard 0.758）；
- 官能团卡片 Top-3：`羧基 / 酯基 / 芳香环`（RDKit 识别；排序来自 GNNExplainer）。

**讲解词**：

> 这是阿司匹林。异质集成把 9 个配置 × 4 个种子共 36 个成员等权平均。右边卡片明确标注了三层来源：重要性数值来自 GNNExplainer，基团是否存在由 RDKit 判定，文字解释只是复述，LLM 不能自己决定哪个基团重要。ESOL 的解释一致性是"高"，所以这张图相对可信。

**兜底**：若页面暂时无图，等 3–5 秒（首次解释需要跑 GNNExplainer）；若报"模型缺失"，说明模型目录未就位，直接跳到 3:20 的版本页话术。

## 1:40–2:40 批量 CSV 与导出

**动作 1**：切到"批量预测"区域，选择文件 `示例批量分子.csv`（11 行，其中最后一行是故意构造的非法 SMILES）。

**动作 2**：任务 `ESOL`、特征档 `FEAT_C`、架构 `GCN`、分析方式 `单模型`，点击"运行批量预测"。

**预期结果**：

- 表格出现 10 条成功结果 + 1 条错误行；
- 错误行提示 RDKit 无法解析（非法 SMILES），但**不会中断整批**；
- 页面显示"成功 10 / 失败 1"（或等价统计）。

**动作 3**：点击"导出 CSV"，得到带 UTF-8 BOM 的结果文件，用 Excel 直接打开无乱码。

**讲解词**：

> 批量接口限制 200 行、单条 SMILES 300 字符。错误是逐行返回的，不会因为一条坏数据让整批失败——这是实际药物筛选场景最常遇到的问题。导出文件带 BOM，Excel 打开中文不乱码。

**兜底**：若无 CSV 上传控件，改用浏览器直接调用接口（备选）：

```
POST /api/batch  (multipart: file=示例批量分子.csv)
```

## 2:40–3:40 解释一致性与官能团（PPT 核心图 4）

**动作**：切回 PPT 第 8 页（解释一致性）。

**讲解词**：

> 同一个分子，换 9 个配置跑 GNNExplainer，ESOL 的 Top-10 原子集合 Jaccard 是 0.76，FreeSolv 是 0.96，判为高；BBBP 只有 0.49，判为中。但排序相关只有 0.35 左右——"哪些原子重要"有共识，"谁排第一"各说各话。所以 Web 给一致性等级，而不是把一张热图当唯一答案。

**动作**：切到第 9 页（官能团）。

**讲解词**：

> 官能团解释是把原子重要性聚合到化学语言。这个 ESOL 分子 Top-3 是芳香环、氯、酰胺。必须强调三层分离：数值只能来自模型归因，基团存在性只能来自 RDKit，文字只是复述。局限也明确：FreeSolv 平均只有 1.2 个可识别基团，7/40 零检出，这时回退到原子级，不编造。

## 常见现场故障与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面打不开 | Flask 未启动/端口占用 | 重新运行 `python src/app.py`；换 5001 端口 |
| 预测报"模型缺失" | `models/feat*` 未就位 | 展示 `reports/model_manifest.json` 与报告结果，跳过现场预测 |
| 首次预测很慢 | GNNExplainer 初始化 | 等 3–5 秒；提前预热一次 |
| LLM 卡片显示"规则模板" | 无 Key/断网/超时 | 正常降级，按"降级设计"讲解，不现场排查网络 |
| 批量全部失败 | CSV 列名不是 `smiles` | 用 `示例批量分子.csv` 模板；确认表头 |
| 导出的 CSV 乱码 | 用了旧版接口 | 重新导出；当前实现为 UTF-8 BOM |
